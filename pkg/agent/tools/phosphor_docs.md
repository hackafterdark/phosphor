Look up Phosphor's own product documentation, compiled into the binary so it always
matches the running build. Use it to answer questions about how Phosphor itself works
or is configured (features, slash commands, tools, phosphor.json, providers, themes,
hooks, security, etc.) from any workspace.

Provide `query` to search the corpus and rank the relevant docs; pass a returned
`path` back in to read that doc; or set `list` to see every available doc.
