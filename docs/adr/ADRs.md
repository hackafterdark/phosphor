# Architecture Decision Records (ADRs)

This directory contains ADRs that document the major architectural decisions that have been made for the project.
They serve as a historical reference for why the project is the way it is today. They reinforce the design
principles and patterns that the project follows.

## ADR Template

All ADRs should follow the template below:

```markdown
# [Title]

- **Status:** Accepted
- **Date:** 2026-06-14
- **Authors:** Phosphor Team
- **Superseded By:** —

## Context
[Background information]

## Decision
[What was decided]

## Rationale / Why This Approach
[Why this decision was made]

## Consequences
[Implications of the decision]
```
