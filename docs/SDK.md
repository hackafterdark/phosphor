# Programmatic Client SDK

The `pkg/client` package is Phosphor's public programmatic SDK. It allows Go developers to embed and run Phosphor session agents in-process within their own applications.

## Overview

The SDK provides a clean, high-level facade (`SessionHandle`) that manages database connections, configuration, provider models, and runtime session orchestration. By wrapping the core logic in `pkg/client`, consumers do not need to deal with TUI-specific orchestration, HTTP servers, or command-line parser details.

## Installation

Import the package in your Go code:

```go
import "github.com/hackafterdark/phosphor/pkg/client"
```

## Basic Usage

The following example demonstrates how to load a configuration, initialize a session in a workspace, subscribe to events, and send a message.

```go
package main

import (
	"context"
	"fmt"
	"os"
	"time"

	"github.com/hackafterdark/phosphor/pkg/client"
)

func main() {
	ctx, cancel := context.WithTimeout(context.Background(), 30*time.Second)
	defer cancel()

	// Path to the workspace folder containing phosphor.json
	workspaceDir := "./my-workspace"

	// 1. Initialize the session handle
	// This automatically loads workspace configuration, connects to the SQLite db,
	// discovers skills, and boots the runtime app.
	h, err := client.NewSession(ctx, workspaceDir)
	if err != nil {
		fmt.Printf("Failed to create session: %v\n", err)
		return
	}
	defer h.Close()

	// 2. Subscribe to message delta events (asynchronous stream)
	unsub, err := h.Subscribe(ctx, client.EventMessageDelta, func(ev client.Event) {
		// Output deltas as they stream in
		fmt.Print(ev.Text)
	})
	if err != nil {
		fmt.Printf("Failed to subscribe: %v\n", err)
		return
	}
	defer unsub()

	// 3. Send a message to the agent
	// This executes the agent turn, triggering tools, permissions, and streaming.
	// You can also capture non-interactive console output using the third argument.
	err = h.SendMessage(ctx, "Explain Go channels in one sentence.", os.Stdout)
	if err != nil {
		fmt.Printf("\nError during run: %v\n", err)
		return
	}

	// Give async events a moment to finish printing
	time.Sleep(100 * time.Millisecond)
	fmt.Println()
}
```

## Session Configuration

You can customize the session options using `SessionOption` functional parameters in `NewSession`:

| Option | Purpose |
|---|---|
| `WithModels(large, small string)` | Override the default model choices for the large and small models. |
| `WithDataDir(dir string)` | Override the default `.phosphor` data directory. |
| `WithConfig(cfg *config.Config)` | Provide a preloaded configuration instead of loading `phosphor.json` from the workspace directory. |
| `WithDB(database *sql.DB)` | Provide an already open `*sql.DB` database connection instead of establishing one from the pool. (The caller retains ownership of the connection lifecycle and is responsible for closing it). |
| `WithSkipMigrations()` | Skip running database schema migrations during connection initialization. |

Example:
```go
h, err := client.NewSession(ctx, workspaceDir,
    client.WithModels("gpt-4o", "gpt-4o-mini"),
    client.WithDB(customDBConn),
    client.WithSkipMigrations(),
)
```

## Event Subscriptions

The SDK supports subscribing to various asynchronous execution events:

| Event Type (`client.EventType`) | Payload Field | Triggered When |
|---|---|---|
| `EventSessionStart` | `SessionID`, `Timestamp` | The agent execution run starts. |
| `EventSessionEnd` | `SessionID`, `Timestamp` | The agent execution run finishes. |
| `EventMessageDelta` | `Text`, `MessageID` | A new text fragment is generated by the LLM. |
| `EventToolCall` | `ToolCallID`, `ToolName`, `ToolInput` | The agent initiates a tool call. |
| `EventToolResult` | `ToolCallID`, `ToolName`, `ToolResult` | A tool execution finishes and returns a result. |
| `EventAgentComplete` | `Text`, `Error` | The agent run finishes successfully or returns an error. |

### Subscribing to Events

You can register a handler for any event type using the `Subscribe` method on the handle:

```go
unsub, err := h.Subscribe(ctx, client.EventToolCall, func(ev client.Event) {
    fmt.Printf("[Tool Call] %s with input: %s\n", ev.ToolName, ev.ToolInput)
})
if err != nil {
    // handle error
}
// Call the unsub function when done to clean up the subscription
defer unsub()
```

Alternatively, you can use the package-level convenience function:
```go
unsub, err := client.Subscribe(h, ctx, client.EventToolCall, handler)
```

## Architecture details

Behind the scenes, `pkg/client` performs the following actions:
1. **Config Loading**: Reads and unmarshals `phosphor.json` inside the specified workspace.
2. **Database Connection**: Establishes a SQLite database connection inside the `.phosphor` (or custom) directory.
3. **Skill Discovery**: Automatically discovers workspace-defined agent skills.
4. **App Instantiation**: Creates and boots `internal/app.App` using the database, config, and skills manager.
5. **Subscription & Event Loop**: Subscribes to the internal pubsub message and completion channels, formatting them into user-facing `client.Event` structures.
